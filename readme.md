To run the app, first download it on your system
open the folder in a code editor such as VS code
open the terminal and run the command below:
pip install -r requirements.txt
then run the training pipeline using the following commmand:
python training_pipeline.py
now run the application using the command:
python app.py
Open your browser and go to http://127.0.0.1:5001/
navigate to the dashboard and click on start AI scan
choose any one of the 3 AI models present to scan
you will see the incoming network traffic getting monitored in the dashboard
